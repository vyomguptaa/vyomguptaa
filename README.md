Every graphic here is generated locally and committed to the repository.<br>
`ascii.svg` is a photo transformed into a character portrait by<br>
[`scripts/make_portrait.py`](scripts/make_portrait.py); the contribution graphics and<br>
section headings are generated by [a scheduled action](.github/workflows/stats.yml)<br>
from the GitHub GraphQL API for `vyomguptaa`.

They animate with SMIL inside the SVG, because GitHub strips scripts from<br>
READMEs — and since nothing loads from a third party, nothing here can<br>
rate-limit or go dark.

The typeface is [JetBrains Mono](scripts/fonts), subset to the characters<br>
each graphic draws and inlined as base64.

Language totals cover public repositories only. `year.svg` uses the portrait's<br>
character ramp: `:` `+` `#` `@`, quiet to loud.
